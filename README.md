Welcome to the aether-tracker website repository!!
-----------------------------------------------------------------------------------------------------------------------------
About:
1. This website was created using Google Antigravity and is currently hosted (as of May 27 2026) on render.
2. This website allows users to see current satellites around the globe of various types.

Website Technicalities:
The website has 2 major portions:
  1. Base and view setup
  2. Satellite Visualisers

  Base and view setup:
    1. This panel allows the user to select their current location (as this affects which satellites they see) and,
    2. Select the type of satellite they want to see(for eg, Space stations, Weather satellites, Starlink constellation, etc.)

  Satellite Visualisers:
    The star of the show, these visualisers help locate and display the satellites on 3 different views:
      1. 2D Radar view; this view looks like a radar scanner and shows the satellites that are currently overhead(above the horizon). The higher the satellite is in the sky, the closer it appears to the center in the view. The user can select a satellite to view information about it like its name, orbit data, etc.
      2. 3D Globe view; this view shows a 3D globe with latitude and longitude markings with the base station highlighted. According to the option checked in the panel, it will either show overhead satellites or all the satellites of the type around the earth. The globe is rendered in 60 fps and is very smooth. Selecting a satellite brings up the information about the satellite with an option to toggle its orbit shown around the earth.
      3. 3D Sky-Dome view; This view simulates a stellarium type environment, where the user is at the center of a dome with overhead satellites shown as if in the sky right now. clicking on a satellite shows information as well as the trajectory of the satellite in the sky.
